# Gunshade Online

Игра Gunshade с общим онлайн-сервером (мультиплеер до 8 игроков + мультиплеер-редактор уровней на 4 человека).

## Что синхронизируется
- Враги: позиции, здоровье, смерть, ИИ работает на сервере — ударил один, изменилось у всех.
- Базука: сундук открыл один — базука появляется у всех (и у зашедших позже).
- Бронежилеты и аптечки забирает тот, кто подобрал; для остальных предмет исчезает.
- Выстрелы, ракеты, взрывы, удары ножом, кровь.
- Все игроки выглядят одинаково (одного цвета).
- 2 бронежилета: каждый забирает один игрок, после этого он пропадает.
- Команды чата: `/pvp on` и `/pvp off` — урон между игроками (пуля 20, нож 35, ракета 70; броня снижает урон); `/enemy kill` — убить всех врагов; `/enemy respawn on|off` — новый раунд, когда все враги убиты (по умолчанию включено). При включённом PvP над игроками видна полоска HP. `/shield set` — всем игрокам +1 щит (макс. 2); `/noclip on|off` — для себя: без коллизии, быстрый бег, мобы не атакуют; `/infinity heat on|off` — для себя: бесконечные жизни.
- Чат: иконка 💬 справа сверху, закрытие — кнопка ✕ (Enter — открыть/отправить, Esc — закрыть).
- **Пользовательские карты**: в меню кнопка «ПОЛЬЗОВАТЕЛЬСКИЕ КАРТЫ» → «+ ДОБАВИТЬ СВОЙ УРОВЕНЬ» → выбрать HTML-файл, экспортированный из редактора (или JSON), ввести название, нажать «ХОСТИТЬ». Карта появится в списке у всех, любой игрок нажимает «ВОЙТИ». У каждой карты свой мир, чат, PvP и враги. Хост может удалить свою карту кнопкой 🗑 (в том же браузере).
- Когда все враги убиты, через 15 секунд начинается новый раунд.

## Мультиплеер редактор (новое)
В главном меню кнопка **«ЗАЙТИ В МУЛЬТИПЛЕЕР РЕДАКТОР»**.
- **Комнаты**: «+ СОЗДАТЬ КОМНАТУ» (название + размер карты 1000/2000/3000/5000, либо «взять мой уровень из обычного редактора»). В комнате до **4 человек**, список комнат виден всем, хост может удалить свою комнату (🗑).
- **Совместное редактирование**: кто-то ставит стену / врага / сундук / хилку / броню / спавн или стирает — это сразу видят все. Курсоры других участников показаны цветом и именем («Игрок 2»).
- **Текстуры**: «🎨 СПРАЙТЫ» — рисунок спрайта (стена, враг, игрок, оружие…) после каждого штриха виден всем.
- **Тест уровня**: кнопка «ТЕСТ УРОВНЯ» заводит в настоящую серверную игру на текущем уровне (враги, сундуки, PvP). Остальные видят тестера прямо на карте редактора (цветной кружок «Игрок N • тест») и статус «в тесте» в шапке. В тест могут зайти несколько человек вместе. Выход — «ВЫЙТИ ИЗ ТЕСТА УРОВНЯ».
- **Чат** (💬, Enter) общий для всех в комнате — и у рисующих, и у тестеров. **Команды** (`/pvp`, `/enemy …`, `/shield set`, `/noclip`, `/infinity heat`, а также новая `/reload`) работают **только в тесте**; вне теста чат просто пишет подсказку.
- `/reload` (в тесте) — перезагрузить тест из актуального уровня редактора (тест — это снимок уровня на момент входа).
- «ОПУБЛИКОВАТЬ КАК КАРТУ» — отправляет текущий уровень комнаты в «Пользовательские карты». «СКАЧАТЬ JSON» / «ЭКСПОРТ HTML» работают как обычно.
- Состояние комнаты хранится в памяти сервера (как и пользовательские карты). Если Render «заснул» или перезапустился, комната исчезает — клиент покажет экран с кнопками «ПЕРЕСОЗДАТЬ КОМНАТУ ИЗ МОЕЙ КОПИИ» и «СКАЧАТЬ УРОВЕНЬ (JSON)»: копия уровня остаётся в браузере. Пустая комната удаляется через 6 часов.
- Лимиты: до 20 комнат одновременно, до 8000 стен, до 80 врагов (те же, что у пользовательских карт). Стены строго по сетке редактора 40×40 (уровни из обычного редактора подходят).
- Для устойчивости сервер каждые 5 секунд рассылает контрольную сумму уровня; если у кого-то уровень разошёлся — он автоматически получает полную копию.

## Структура
```
server.js        — сервер (HTTP + WebSocket)
package.json
render.yaml      — настройки для Render
public/index.html — игра
```
Если у тебя есть `player.png` — положи его в папку `public/`.

## Запуск локально
```
npm install
npm start
```
Открой http://localhost:3000 и нажми «ОБЩИЙ СЕРВЕР (ОНЛАЙН)».

## Деплой на Render
1. Загрузи все файлы на GitHub (репозиторий, файлы в корне).
2. На render.com: **New → Web Service** → выбери репозиторий.
3. Настройки: Runtime **Node**, Build Command `npm install`, Start Command `node server.js`, Health Check Path `/health`. (Либо **New → Blueprint** — настройки возьмутся из `render.yaml`.)
4. Нажми Deploy и открой выданную ссылку `https://...onrender.com`.

Важно:
- Бесплатный план Render засыпает после ~15 минут без посетителей; первое подключение может занять до минуты — игра сама переподключается.
- Запускай только 1 экземпляр сервиса (состояние мира хранится в памяти).
- Играть нужно по ссылке Render, а не открывая index.html из файла.

## Пользовательские карты: ограничения
- До 8 игроков на карту, до 40 карт одновременно, размер карты до 6000×6000, до 8000 стен, до 80 врагов, файл до ~1.4 МБ.
- Карты хранятся в памяти сервера: при перезапуске или «засыпании» Render они пропадают (для постоянного хранения нужен платный диск/БД).
- Пустая карта удаляется через 6 часов.

## Редактор уровней
- Кнопка «🎨 СПРАЙТЫ»: пиксельный редактор для стены, врага, игрока, пистолета, ножа, базуки, хилки, брони, сундука, пули и ракеты. Рисунок сохраняется в уровне (JSON / HTML-экспорт / пользовательские карты онлайн) и так же выглядит в игре.
- Tab / Shift+Tab — размер кисти (1×1…5×5) для стены, врагов, хилок, брони и ластика.
- В игре колёсико мыши отдаляет и приближает камеру.
